Email signature and Outlook setup

Make a signature with the new BLISS logo, then connect your mailbox to Outlook. Your emails stay on the mail server, so they appear in Outlook automatically.

1. Your signature

Fill in your details. Leave a field empty to hide that line.

"Copy signature" copies it with the logo and formatting, ready to paste into Outlook. If your browser blocks copying, select the signature above with the mouse and press Ctrl+C. "Copy HTML code" is for tools that ask for HTML.

2. Add the mailbox to Outlook

Use these settings for info@ and for any other @blissbathandkitchen.com mailbox (change the email address).

Email address / usernameinfo@blissbathandkitchen.com
PasswordThe mailbox's own password (the one used for webmail)
Account typeIMAP
Incoming servermail.blissbathandkitchen.com, port 993, SSL/TLS
Outgoing server (SMTP)mail.blissbathandkitchen.com, port 465, SSL/TLS
Outgoing server needs sign-inYes, same username and password as incoming
Outlook for Windows (new) and Mac
  1. Settings (gear) → Accounts → Email accounts → Add account.
  2. Type the email address and choose Continue.
  3. When asked for the account type, pick IMAP.
  4. Enter the password, then open Show more and fill in the servers and ports from the table.
  5. Choose Continue. Your folders start downloading.
Outlook classic (Microsoft 365, 2019, 2021)
  1. File → Add Account.
  2. Type the email address, open Advanced options, tick Let me set up my account manually, choose Connect.
  3. Pick IMAP.
  4. Incoming: server and port 993, encryption SSL/TLS. Outgoing: server and port 465, SSL/TLS.
  5. Enter the password and choose Connect, then Done.
Outlook on iPhone or Android
  1. Add account → Add email account, type the address.
  2. Choose IMAP (on Android tap "Setup account manually" first).
  3. Turn on Advanced settings and fill in the servers, ports and password from the table.
  4. Tap the tick to finish.

3. Moving your existing emails

Emails in webmail now

Nothing to move

With IMAP, Outlook shows what is on the mail server: Inbox, Sent and every folder appear by themselves after the account is added. Large mailboxes can take an hour or more on the first sync.

Emails only on an old computer

Copy them into the new account

  1. If the old mail is in Outlook on that computer (often a POP account), add the new IMAP account there first, as above.
  2. Drag the old folders (Inbox, Sent, others) onto the new account in the folder list. They upload to the server.
  3. Once they appear in webmail, every device sees them.

If the old mail is in a .pst file, open it in Outlook classic (File → Open & Export → Open Outlook Data File) and drag the folders across the same way.

Emails in another provider

Gmail, another host or an old domain

Add both accounts to Outlook classic and drag the folders from the old account to the new one. For very large mailboxes, ask SiteGround about their email migration tool.

4. Add the signature in Outlook

Outlook for Windows (new), Mac and Outlook on the web
  1. Click Copy signature above.
  2. Settings → Accounts (or Mail) → Signatures → New signature.
  3. Name it "Bliss", click in the box and press Ctrl+V (Cmd+V on Mac).
  4. Choose it as the default for new messages and replies, then Save.
Outlook classic
  1. Click Copy signature above.
  2. File → Options → Mail → Signatures → New, name it "Bliss".
  3. Click in the edit box and press Ctrl+V.
  4. Pick it for new messages and replies/forwards for the right account, then OK.
Phones

The Outlook phone app only keeps plain text signatures. Use: your name, Bliss Bath & Kitchen, the main phone number and the website.

The logo loads from the Bliss website, so it stays sharp and current. Some recipients' email programs hide images until they choose "show images"; the text part of the signature always shows.
